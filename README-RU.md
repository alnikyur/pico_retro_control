# PicoSwitch: тест внешнего светодиода на GP15

Статус: исходники изменены, проверены сигнатуры API таймера и git diff --check. Полная сборка и проверка на плате НЕ выполнены. Готового UF2 в архиве нет. Workflow сборки также ещё не запускался.

Только Raspberry Pi Pico W (RP2040). При каждом успешном подключении контроллера GP15 выдаёт высокий уровень на 200 мс, затем опускается. Если второй контроллер подключается во время импульса, отсчёт 200 мс начинается заново. Таймер BTstack не блокирует Bluetooth/USB. Встроенный светодиод и USB-отчёты не изменены.

## Подключение при отключённом USB

- GP15, физический контакт 20 -> резистор 470 Ом -> анод красного светодиода (длинная ножка).
- Катод светодиода (короткая ножка / плоская сторона корпуса) -> GND, физический контакт 18.
- Pico питается только от USB ПК в этом тесте.
- Не соединяйте GP15 с Power/J2 Raspberry Pi: контроля состояния питания здесь ещё нет.

## Как получить UF2 через GitHub Actions

1. Создайте свой репозиторий GitHub.
2. Загрузите содержимое этого архива в корень, сохранив пути src/pico_switch_platform.c и .github/workflows/build-led.yml. Если скрытая папка .github не видна, создайте файл через Add file -> Create new file с полным путём .github/workflows/build-led.yml и вставьте его содержимое.
3. Откройте Actions -> Build PicoSwitch LED test -> Run workflow.
4. После успешной сборки скачайте артефакт PicoSwitchWGA-GP15-LED и распакуйте UF2.
5. Сохраните исходную рабочую прошивку. Подключите Pico с зажатой BOOTSEL и скопируйте новый UF2 на RPI-RP2. flash_nuke не требуется.

## Проверка

- После загрузки, без геймпада: внешний LED выключен.
- После подключения геймпада: одна вспышка 200 мс.
- Нажатия кнопок и движение стиков: дополнительных вспышек нет, USB-контроллер работает.
- Выключить и включить геймпад: новая вспышка после подключения.
- Повторить 5 раз и проверить управление в joy.cpl/игре.

Если сборка завершится ошибкой, сохраните лог: прошивка не считается готовой до успешной сборки. После прошивки может понадобиться повторное сопряжение: исходный PicoSwitch удаляет Bluetooth-ключи при запуске, эта логика в тесте сохранена.
